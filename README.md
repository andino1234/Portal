# Portal Insight LATAM

Portal interno que centraliza el acceso a las aplicaciones corporativas de Insight LATAM desde una sola página: monitoreo de licitaciones (LicitScraper), solicitudes internas (vacaciones y permisos) y mantenimiento.

## Características

- Página de inicio con accesos directos a cada aplicación.
- Vista de portal que carga las aplicaciones dentro de un `iframe`, con alternativa para abrirlas en otra pestaña cuando el sitio bloquea la carga embebida.
- Páginas de política de privacidad y términos de servicio.
- Diseño *responsive*.

## Tecnologías

HTML5 · CSS3 · JavaScript vanilla

## Estructura

```text
index.html     Inicio con accesos a las aplicaciones
portal.html    Vista de portal con las apps embebidas
privacy.html   Política de privacidad
terms.html     Términos de servicio
styles.css     Estilos
assets/        Logotipo e imágenes de las aplicaciones
```

## Ejecución local

Abre `index.html` en el navegador o usa un servidor estático (`npx serve .`).
